# CanvasLink: Android по локальной сети

Экспериментальная интеграция: планшет показывает **всё текущее окно CanvasTTY**
и управляет им. Доступ включает терминалы, настройки и видимые секреты.
Подключайте только своё доверенное устройство.

1. Установите APK доверенной сборки на Android 8 или новее.
2. На компьютере откройте **Настройки → CanvasLink → Включить доступ**.
3. Откройте CanvasLink на планшете, выберите найденный компьютер и введите код.
   Оба устройства должны быть в одной локальной сети без изоляции клиентов.
   Ручной адрес нужен только при недоступном обнаружении.
4. Коснитесь терминала: появится клавиатура. Ввод передаётся напрямую;
   Enter выполняет команду. В панели есть вставка и прерывание.
5. «Забыть устройство» отзывает сессию. «Выключить доступ» останавливает сеть,
   видео и управление. При новом запуске компьютера доступ выключен.

Одноразовый код действует две минуты. Сессия — до двенадцати часов; смена адреса
может потребовать нового подключения. При обрыве команды не повторяются
автоматически: сначала проверьте терминал. Вставка берёт буфер Android.

Отдельное приложение на компьютере не требуется. Очки Even G2 и Web companion
сохраняют свои отдельные коды и разрешения. Порт 3499 не открывайте в Интернет.

Проверенная пользователем версия работала на Mac с планшетом Android 12.
Этот перенос в исходники проходит отдельные проверки. Реальная работа с
Windows и Linux пока не подтверждена; плавность 30 FPS не обещается.
Отладочные APK разных сборок могут иметь разные подписи и не устанавливаться
поверх друг друга. Рабочую установленную версию сохраняйте до проверки новой.

Команды сборки, устройство защиты и границы проверки: [canvaslink.md](canvaslink.md).
