# CanvasLink 1.0: Android по локальной сети

Экспериментальная интеграция: планшет показывает **всё текущее окно CanvasTTY**
и управляет им. Доступ включает терминалы, настройки и видимые секреты.
Подключайте только своё доверенное устройство.

1. Установите [CanvasLink 1.0 на Android 8+](https://github.com/howdeploy/CanvasTTY/releases/tag/canvaslink-v1.0.0).
   В **Настройки → CanvasLink** есть кнопка **«Скопировать промпт агенту»**:
   она копирует инструкцию по USB/ADB с точной ссылкой и SHA-256 APK.
   Владелец включает USB-отладку и подтверждает RSA-запрос на Android;
   агент устанавливает приложение на выбранное устройство с сохранением данных.
   Нужна CanvasTTY 1.8.3 или новее. Для обновления существующего **CanvasLink DEV**
   выберите `CanvasLink-1.0.0-dev.apk`: сохраняются идентификатор приложения и ключ.
   При конфликте подписи старой alpha остановитесь, не удаляя данные;
   DEV-приложение можно установить рядом с ней.
2. На компьютере откройте **Настройки → CanvasLink → Включить доступ**.
3. Откройте CanvasLink на планшете, выберите найденный компьютер и введите код.
   Оба устройства должны быть в одной локальной сети без изоляции клиентов.
   Ручной адрес нужен только при недоступном обнаружении.
4. Коснитесь терминала: появится клавиатура. Ввод передаётся напрямую;
   Enter выполняет команду. В панели есть вставка и прерывание.
5. «Забыть устройство» отзывает сессию. «Выключить доступ» останавливает сеть,
   видео и управление. При новом запуске компьютера доступ выключен.

Одноразовый код действует две минуты. Сессия — до двенадцати часов; смена адреса
может потребовать нового подключения. При обрыве команды не повторяются
автоматически: сначала проверьте терминал. Вставка берёт буфер Android.

При включённом VPN Android выбирает локальную сеть Wi-Fi/Ethernet с маршрутом
к адресу ПК; HTTP использует её напрямую без прокси и без перехода на мобильную
сеть. На Android 13+ поиск также ограничен этими сетями; на старых версиях
сохранены системный поиск и ручной адрес. На Linux обнаружение ПК привязано
к физическим LAN-интерфейсам. Если компьютер не найден, раскройте
**«Компьютер не находится?»** на телефоне и введите его локальный IPv4 с портом,
например `192.168.0.171:3499`.

Сопряжение и соединение видео/управления — разные этапы. Ожидание подключения
ограничено 30 секундами; кнопка **«Проверить связь»** запускает новую попытку.
При смене сети старый канал ввода закрывается; команды не воспроизводятся.
Маршрутизацию WebRTC внутри WebView нужно отдельно проверить на устройстве.

VPN должен разрешать локальные подключения: одного TCP-порта 3499 недостаточно
для обнаружения и WebRTC. Kill switch и системное **«Блокировать соединения без
VPN»** могут запрещать прямую связь. CanvasLink не меняет эти настройки:
разрешите локальную сеть или добавьте приложение в исключения, если VPN это
поддерживает. Совместимость со всеми VPN и версиями WebView не гарантирована.

Отдельное приложение на компьютере не требуется. Очки Even G2 и Web companion
сохраняют свои отдельные коды и разрешения. Порт 3499 не открывайте в Интернет.

Исходная версия проверялась пользователем на Mac с планшетом Android 12;
интеграционная LAN/VPN-версия получила положительный отзыв на Linux с Android.
Это отдельные пользовательские проверки; полная проверка всех платформ
ещё не завершена, плавность 30 FPS не обещается.
Отладочные APK разных сборок могут иметь разные подписи и не устанавливаться
поверх друг друга. Рабочую установленную версию сохраняйте до проверки новой.

Исходная реализация CanvasLink — вклад @teo-nex в #166; предыдущая alpha
доступна в его репозитории [CanvasLink](https://github.com/teo-nex/CanvasLink).
Версия 1.0 публикуется здесь с постоянной подписью владельца проекта.
URL, SHA-256 и отпечаток сертификата закреплены в `src/shared/canvasLinkInstall.ts`.
Наши дополнения: LAN/VPN-маршрутизация, ограниченное ожидание подключения,
восстановление без повторения ввода, мобильная оболочка и сборки normal/DEV.
Исходные коммиты автора сохранены. Приватный ключ в Git не включается.
При несовместимой подписи агент останавливается: удаление приложения и данных не выполняется.

Команды сборки, устройство защиты и границы проверки: [canvaslink.md](canvaslink.md).
