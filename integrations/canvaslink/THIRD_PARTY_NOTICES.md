# Dependencies

- Electron 43.7.7 — MIT; Chromium and other bundled notices remain inside the
  Electron distribution (`LICENSE`, `LICENSES.chromium.html`).
- bonjour-service 1.3.0 — MIT.
- secure-remote-password 0.3.1 — MIT.

Transitive dependency licenses remain in their installed package directories.
The CanvasTTY desktop bundle retains production dependency licenses and Electron's
original bundled notices. Android uses platform APIs and contains no embedded
third-party Java libraries. No RustDesk or spacedesk source or binaries are used.

## Onest

Bundled Android UI font, from google/fonts/ofl/onest (Onest Project Authors).
SIL Open Font License 1.1; full license: `android/assets/onest-OFL.txt`.
Source: https://github.com/google/fonts/tree/main/ofl/onest

## Lucide icons

Android inline SVG symbols reuse official Lucide geometry from CanvasTTY's
`src/renderer/src/assets/icons/lucide`. Keyboard, corner-down-left and delete were
retrieved from https://github.com/lucide-icons/lucide/tree/main/icons on 2026-10-26.
ISC / MIT notices are bundled as `android/assets/lucide-LICENSE.txt`.
